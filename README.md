# hxwl-04 乳牙治疗计划台

在原根管看板基础上扩展的儿童牙科乳牙治疗计划台：按牙位登记患儿、治疗阶段、预计次数与本次监护人，到诊后经家长确认才能推进。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 本地持久化）

## 分层结构

- 记录层
  - `src/domain/types.ts`：牙位计划的数据结构
  - `src/storage/plansStore.ts`：本地读写，重新打开后阶段、到诊次数、联系安排仍在
- 判断层
  - `src/domain/rules.ts`：纯函数业务规则，页面和存储都不自行判断
- 页面层
  - `src/components/*`、`src/App.tsx`：看板、建档表单、牙位卡、侧栏
  - `src/hooks/usePlans.ts`：页面与判断层之间的桥接（执行规则、统一落盘、错误提示）

## 接诊规则

- 流程：前台**登记本次到诊** → 核实**本次监护人**（可能临时换人）→ **家长确认** → 才能推进下一阶段
- 阶段：开髓拔髓 → 封药消毒 → 根管充填 → 治疗完成；每次复诊需重新登记到诊、重新确认监护人
- 孩子出现**明显疼痛或肿胀**：本次安排转急诊，原阶段与次数保留，等待重排
- **连续两次未到诊**：自动进入联系名单，记录联系安排，不能直接算完成
